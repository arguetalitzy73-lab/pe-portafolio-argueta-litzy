# Portafolio de evidencias de Programación Estructurada

**Universidad de Oriente · Ingeniería en Desarrollo de Software · 2026**

Organiza las evidencias de las **sesiones 10 a 26**, ambas incluidas. Las prácticas quedan fuera de esta entrega.

## Cómo organizar tu repositorio

1. Si vas a crear un repositorio para esta entrega, selecciona **Use this template → Create a new repository** en GitHub. Puedes usar el nombre `pe-portafolio-apellido-nombre`.
2. Si ya tienes un repositorio para la entrega, usa el índice de abajo para organizar tus evidencias con los mismos nombres de carpetas.
3. Coloca en cada carpeta los archivos que trabajaste en esa sesión. Si la evidencia tiene varios archivos, guárdalos juntos y conserva su organización interna.

Cada carpeta tiene un `README.md` que identifica el tema de la sesión. Agrega tus evidencias dentro de la carpeta, junto a ese archivo.

La sesión 10, por ejemplo, puede quedar así si tu evidencia es un archivo TypeScript:

```text
sesiones/sesion-10/
    README.md
    funciones-tipadas.ts
```

## Cómo subir los cambios y entregar

Si creaste tu repositorio con la plantilla, clona **tu propia copia** y abre esa carpeta en VS Code. Sustituye `TU-USUARIO` y el nombre del repositorio por los datos de tu copia.

```bash
git clone https://github.com/TU-USUARIO/pe-portafolio-apellido-nombre.git
cd pe-portafolio-apellido-nombre
```

Después de colocar las evidencias, revisa tus cambios y súbelos a GitHub.

```bash
git status
git add .
git commit -m "Agrega evidencias de las sesiones 10 a 26"
git push -u origin main
```

Abre tu repositorio en GitHub y verifica que estén las 17 carpetas y que cada una contenga sus evidencias. Entrega **el enlace de tu repositorio** en la actividad de Canvas y verifica que la docente tenga acceso. Consulta en Canvas la fecha indicada para esta entrega.
