# Sesión 21
**Arreglos tipados**
Declaración, acceso, modificación, length e índices válidos

## 1: Declaración y acceso
Modalidad: individual. Resuelve cada reto en un bloque identificado. Antes de ejecutar, predice el resultado de los accesos solicitados.

- Calificaciones: declara un arreglo de cinco calificaciones, muestra el arreglo completo, la tercera calificación y la cantidad almacenada.
- Equipo de trabajo: guarda cuatro nombres y muestra el primero, el último mediante length y la cantidad de integrantes.
Pregunta de análisis: explica por qué la tercera posición utiliza el índice 2.


## 2: Modificación y detección de errores
- Actualización de precios: declara cuatro precios de productos escolares, muestra el arreglo original, corrige el segundo precio y presenta el arreglo actualizado.

- Acceso fuera de rango: analiza const departamentos: string[] = ["San Miguel", "La Unión", "Morazán"]; y determina qué sucede al consultar departamentos[3]. Corrige el acceso y muestra el último elemento con length.
Justificación: escribe cuántos elementos contiene el arreglo anterior y cuáles son sus índices válidos.

## 3: Tipos y sintaxis
- Asistencia semanal: representa con valores booleanos la asistencia de lunes a viernes. Muestra el registro completo, el lunes, miércoles y viernes, y la cantidad de días.
- Dos formas de declarar: escribe la misma lista de tres municipios con string[] y Array<string>. Accede al segundo municipio de ambos arreglos y explica cuál sintaxis te resulta más legible.
