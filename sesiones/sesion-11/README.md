# Sesión 11

**Parámetros opcionales y valores por defecto en funciones de TypeScript**

## Ejercicio 1. Saludo para estudiantes
La plataforma académica de la universidad necesita generar saludos personalizados. Cree
una función que reciba obligatoriamente el nombre de un estudiante y permita proporcionar
su apellido de manera opcional.
Si se recibe el apellido, el saludo deberá mostrar el nombre completo. Si no se recibe,
deberá utilizar solamente el nombre.
Pruebe la función con un estudiante cuyo apellido sea conocido y con otro del que
solamente se tenga el nombre.

## Ejercicio 2. Descuento predeterminado
Una librería de San Miguel aplica normalmente un descuento del 10 % a sus promociones.
Cree una función que reciba el precio de una compra y un porcentaje de descuento.
El porcentaje deberá tener un valor por defecto del 10 %, pero la función también deberá
permitir aplicar un porcentaje diferente cuando la promoción lo requiera.
Realice una prueba utilizando el descuento predeterminado y otra proporcionando un
porcentaje distinto.

## Ejercicio 3. Registro de estudiante
El sistema de nuevo ingreso debe generar un mensaje con el nombre y la carrera
seleccionada por cada estudiante. Debido a que la mayoría pertenece a Ingeniería en
Desarrollo de Software, esa carrera deberá asignarse como valor por defecto.
La función debe permitir registrar estudiantes de otras carreras cuando se proporcione un
valor diferente.
Realice al menos dos pruebas que permitan observar ambos comportamientos.

## Ejercicio 4. Precio final con impuesto opcional
Un pequeño negocio necesita calcular el precio final de sus productos. Cree una función
que reciba obligatoriamente el precio base y permita recibir opcionalmente un porcentaje de
impuesto.
Si se proporciona el impuesto, deberá calcularse y sumarse al precio. Si se omite, el precio
final deberá permanecer igual al precio base.
Muestre los resultados con dos cifras decimales.

## Ejercicio 5. Configuración de una búsqueda
Una aplicación de consulta de cursos muestra normalmente cinco resultados por búsqueda.
Cree una función que reciba el texto que desea buscar y un número máximo de resultados
cuyo valor por defecto sea 5.
La función deberá mostrar un mensaje que indique qué se está buscando y cuántos
resultados pueden presentarse. Compruebe su comportamiento utilizando el límite
predeterminado y proporcionando un límite diferente.
