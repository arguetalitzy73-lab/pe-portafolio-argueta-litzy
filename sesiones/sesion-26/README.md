# Sesión 26

**Recorridos de arreglos (`for`, `for...of`, `forEach`)**
## Inventario de una tienda 
Una tienda tiene una lista tipada de productos. Presenta cada nombre en consola mediante for...of, de manera que el programa funcione aunque se agreguen nuevos productos.

## Listado de estudiantes:
Una docente necesita mostrar la posición y el nombre de cada estudiante de un grupo. Utiliza un for tradicional e identifica cómo convertir el índice del arreglo en un número de lista comprensible para las personas.

## Reporte de calificaciones:
Un coordinador dispone de un arreglo de notas numéricas. Utiliza forEach() para imprimir cada calificación con un mensaje uniforme y formato legible.

## Conteo por condición:
En un registro de notas, determina cuántos estudiantes alcanzaron la nota mínima de aprobación. Decide qué recorrido utilizar y combina el ciclo con un condicional; muestra el conteo final.

## Total de ventas
Una cafetería universitaria almacena los precios de sus ventas en un arreglo de números. Recorre los importes y calcula cuánto dinero se recaudó en total; presenta el resultado en dólares con dos decimales.

## Comparación de recorridos
Una biblioteca necesita mostrar los títulos de sus libros. Resuelve la misma necesidad con for, for...of y forEach(). Compara las tres versiones y explica cuál consideras más legible y en qué situación elegirías otra.
